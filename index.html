01 / About

Backend specialist who treats AI as a teammate, not a toy. Pragmatic, test-driven, comfortable with ambiguity.

I currently work as a mid-senior developer at Dayforce, where I split my time between deep .NET work — APJ payroll localisation, internal NuGet decomposition of a long-lived monolith — and the platform plumbing that keeps releases safe: SonarQube gates in Azure DevOps, test-coverage lifts, and SQL/EF query tuning on high-traffic endpoints.

Outside of the platform itself, I've leaned hard into agentic development — running Copilot with MCP servers wired to Atlassian, GitHub and MSSQL, and using Claude Code for production work alongside my own projects. The point isn't that AI writes code for me; it's that I've redesigned my loop around it.

02 / AI-integrated development

An agentic workflow, used in production every day. From ticket triage to merge-ready PR.

Differentiator

I don't just use AI tools — I build the loop around them.

My daily workflow uses Copilot with MCP integrations (Atlassian, GitHub, MSSQL) to pull context directly from JIRA, repos and the database, and Claude Code for longer-horizon refactors and verification. The same loop powered my Victoria Crime Atlas project end-to-end: UI designed with Claude Design, implementation generated and iterated with Claude Code.

The skill I bring isn't prompt-typing — it's context engineering, prompt design, and disciplined verification of generated output so it ships safely.
